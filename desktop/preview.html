v3 改了什么

  • 外边框：整块内容围一圈黑线，屏幕像一块摆件而不是一张截图
  • 页眉：宋体黑大字 + 右侧时间 + 一条粗横线（三屏统一）
  • 待办屏：方块进度条 + 复选框 + 优先级实心方点 + 删除线标完成 + 右对齐日期；逾期项自动排到最前
  • 日程屏：竖直时间轴（圆点连成一线），进行中的整块反白 + 空心大圈；底部横轴固定 08:00–20:00，事件落成小圆点，「现在」是贯穿的粗竖线
  • 待机屏：左侧《快雪时晴帖》局部（黑墨白纸，正是 1-bit 的原生语言），右侧时间 + 倒计时 + 今日概览

没变的（刻意保留）

  • 排版全在 Mac 上做，板子只贴 15000 字节的 1-bit 帧
  • 11px 可读下限，小字自动提到 W6 —— 1-bit 上细笔画会被阈值化打散
  • 层次只靠反白 / 分隔线粗细 / 字重 / 留白，不靠颜色
  • 底部反白按键条只放在待机屏（它是首页），另两屏靠页眉标识自己在哪
  • 日程事件多到 8 条以上时，副行自动让位、只保标题，底部提示「还有 N 项」—— 1-bit 400×300 是硬边界
